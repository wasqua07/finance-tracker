# 💰 Finance Tracker

A simple and responsive web application for tracking personal income and expenses. The application helps users monitor their financial activity and visualize their spending through charts.

## ✨ Features

- ➕ Add income and expense transactions
- 🗑️ Delete transactions
- 💰 Track total income
- 💸 Track total expenses
- 📊 Visualize expenses using charts
- 💾 Store transaction data using browser Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage
